## 🚀 Projetos em destaque

### [ABISSAL](https://github.com/gqbressanin/ABISSAL) · Unity / C#
Jogo 2D de exploração submarina em pixel art. O jogador comanda um mergulhador que desce ao fundo do oceano para coletar amostras e voltar à superfície antes que o oxigênio acabe, fugindo de predadores, águas-vivas e fontes termais.

- Arquitetura organizada por sistemas: oxigênio, profundidade, iluminação por zona, coleta de amostras e perigos
- Ferramentas de editor próprias em C# que geram sprites, mapa e terreno por código
- Testes automatizados das regras da expedição
- Feito para a disciplina de Desenvolvimento de Jogos Digitais

### [exercicios-python-ia](https://github.com/gqbressanin/exercicios-python-ia) · Python
Série de exercícios com modelos de linguagem usando **tool calling**: o modelo decide qual função Python chamar e com quais argumentos para responder ao usuário.

- Integração com a API da Groq (Llama 3.3 70B) e o SDK da OpenAI
- Definição de ferramentas por JSON Schema e execução das funções escolhidas pelo modelo
- Chaves de API protegidas em variáveis de ambiente
