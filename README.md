**O que dá pra ver aqui**

[ABISSAL](https://github.com/gqbressanin/ABISSAL) é um jogo 2D de mergulho feito em Unity para a matéria de Desenvolvimento de Jogos Digitais. Você desce até o fundo, pega amostras e tenta voltar antes de o oxigênio acabar. Em vez de desenhar os sprites e o mapa na mão, escrevi ferramentas de editor em C# que geram tudo por código. As regras da expedição têm testes automatizados.

[exercicios-python-ia](https://github.com/gqbressanin/exercicios-python-ia) são exercícios de tool calling com o Llama 3.3 pela API da Groq. O modelo lê a pergunta, decide qual função Python chamar e o programa executa e devolve o resultado.
